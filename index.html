UI 下載
FXP - BY 老哥
目前版本：v0.11
檔案功能介紹
顯示角色目前經驗值、升級所需經驗值以及目前的經驗加成狀態， 讓練級時可以直接掌握經驗進度。
檔案使用介紹
安裝後自動顯示。
可自由移動顯示位置，並可調整背景與顯示大小。
小地圖 X 按鈕可開啟相關設定。
下載 FXP v0.11
FAR - BY 老哥
目前版本：v0.04
檔案功能介紹
開啟商人時，自動出售安全的灰色垃圾物品， 並自動使用角色自己的金錢修理裝備。
檔案使用介紹
無需任何設定。
與商人 NPC 對話後自動執行。
不使用公會資金修理裝備。
下載 FAR v0.04
FWM - BY 老哥
目前版本：v0.05
檔案功能介紹
讓遊戲原本固定位置的合併背包可以自由拖曳， 並能調整整個背包的顯示大小。
檔案使用介紹
抓住背包上方標題區即可自由移動。
滑鼠位於背包區域時，按住 Ctrl＋滑鼠滾輪調整大小。
Ctrl＋向上滾＝放大；Ctrl＋向下滾＝縮小。
位置與大小會自動保存。
下載 FWM v0.05
FWT - BY 老哥
目前版本：v0.53
檔案功能介紹
顯示角色目前所在的 World ID／位面資訊， 方便確認角色目前所在的遊戲位面。
檔案使用介紹
安裝後即可使用。
小地圖 F 按鈕可開啟介面。
目前版本以本機位面偵測與顯示功能為主。
下載 FWT v0.53

UI 安裝方式

1. 下載需要的 UI ZIP 壓縮檔。
2. 將 ZIP 解壓縮。
3. 將 UI 資料夾放入《魔獸世界：永恆》的 AddOns 資料夾。
4. 重新啟動遊戲或輸入 /reload。
5. 在角色選擇畫面確認插件已啟用。
