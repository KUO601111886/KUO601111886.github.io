FQT｜任務提醒
目前版本：v0.42
檔案功能介紹
  1. 任務進度增加或完成時播放提示音效。
  2. 任務進度可顯示於個人、附近或組隊頻道。
  3. 點選任務怪時，可顯示該任務怪的任務進度。
  4. 可自行調整感應距離與角度。
  5. 提醒視窗可選擇全黑／半透明／透明背景，並可自由調整大小及位置。
檔案使用介紹
  1. 安裝後，小地圖會出現按鈕。
  2. 點擊按鈕開啟設定視窗。
  3. 可自行勾選相關設定。
  4. 預設所有功能皆為開啟狀態。
  5. 視窗可使用右上角 X、ESC 或「完成」關閉。

FBUFF｜自我BUFF監控
目前版本：v1.99
檔案功能介紹
支援多職業，自動監控自身 BUFF 與施放DOT時間。
檔案使用介紹
  1. 安裝後自動顯示。
  2. 可監看使用者放出的buff或dot。
  3. ctrl+左鍵可移動位置，可調整忽略名單。
  4. 小地圖上會有按鈕，可開啟相關設定。
  5. 戰鬥中無法進行設定。

FXP｜遊戲延遲及位面顯示
目前版本：v0.63
檔案功能介紹
顯示目前遊戲幀數、延遲狀態、經驗加成、現在位面..等遊戲現在狀態。
檔案使用介紹
  1. 安裝後自動顯示。
  2. 可自由移動位置，並可調整背景與顯示大小。
  3. 小地圖上會有按鈕，可開啟相關設定。

FEASY｜便利工具
目前版本：v0.08
檔案功能介紹
  1. 自動出售灰色垃圾物品。
  2. 與可修理裝備的商人互動時，自動修理裝備。
  3. 提供郵箱加強功能，方便郵件操作。
  4. 商人及其他遊戲視窗可自由移動。
  5. 背包可自由移動，並可放大／縮小。
  6. 可將小地圖上的插件按鈕集中收納，減少小地圖周圍按鈕雜亂。
檔案使用介紹
  1. 安裝後，小地圖會出現按鈕。
  2. 點擊小地圖按鈕開啟設定。
  3. 視窗可使用右上角 X、ESC 或「設定完成」關閉。

UI 安裝方式

1. 下載需要的 UI ZIP 壓縮檔。
2. 將 ZIP 解壓縮。
3. 將 UI 資料夾放入《魔獸世界：永恆》的 AddOns 資料夾。
4. 安裝完畢後，可以在遊戲對話框中輸入/reload 或是重新啟動遊戲。
5. 如果沒有啟動，可在遊戲中，按下ESC--插件，確認是否啟用打勾。
