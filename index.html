FBUFF｜自我BUFF監控
目前版本：v0.81
檔案功能介紹
支援多職業，自動監控自身 BUFF 與施放DOT時間。
檔案使用介紹
  1. 安裝後自動顯示。
  2. 可自由移動位置，並可調整忽略名單。
  3. 小地圖上會有 B 按鈕，可開啟相關設定。
  4. 戰鬥中無法進行設定。

FXP｜經驗值加成顯示
目前版本：v0.11
檔案功能介紹
顯示角色目前經驗加成狀態，讓練級時可以直接掌握經驗進度。

  1. 安裝後自動顯示。
  2. 可自由移動位置，並可調整背景與顯示大小。
  3. 小地圖上會有 X 按鈕，可開啟相關設定。

FAR｜自動賣垃圾與修理
目前版本：v0.04
檔案功能介紹
  1. 開啟商人時，自動出售安全的灰色垃圾物品。
  2. 開啟修理裝備商人時，自動修理裝備。
檔案使用介紹
  1. 無需任何設定。
  2. 與 NPC 對話後自動執行。
  3. 小地圖上不會有按鈕。
下載 FAR
FWM｜背包自由移動／縮放
目前版本：v0.05
檔案功能介紹
  1. 原本固定位置的合併背包可以自由拖曳。
  2. 可以調整背包顯示大小。
檔案使用介紹
  1. 抓住背包上方標題區即可自由移動。
  2. 滑鼠位於背包區域時，按住 Ctrl＋滑鼠滾輪調整大小。
  3. Ctrl＋向上滾＝放大；Ctrl＋向下滾＝縮小。
  4. 背包位置與大小會自動保存。
下載 FWM
FWT｜位面交換器（半成品）
目前版本：v0.54
檔案功能介紹
  1. 顯示自己目前位面。
  2. 顯示他人目前所在位面。
  3. 可向他人申請組隊，將自己改變到他人的位面。
  4. 挖礦、採集、獵人抓稀有寵物，很好用。
檔案使用介紹
  1. 安裝後即可使用。
  2. 有安裝本 UI 且為同陣營的人才能看到彼此。
  3. 小地圖 F 按鈕可開啟介面。
  4. 因為需要同陣營多人協助測試本 UI，目前沒有人能幫忙， 只能先提供偵測自己位面為主。等到有人願意幫忙測試， 成功的時候會再做更新。

UI 安裝方式

1. 下載需要的 UI ZIP 壓縮檔。
2. 將 ZIP 解壓縮。
3. 將 UI 資料夾放入《魔獸世界：永恆》的 AddOns 資料夾。
4. 安裝完畢後，可以在遊戲對話框中輸入/reload 或是重新啟動遊戲。
5. 如果沒有啟動，可在遊戲中，按下ESC--插件，確認是否啟用打勾。
