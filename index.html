FQT｜任務提醒
目前版本：v0.40
檔案功能介紹
  1. 任務進度增加或完成時播放提示音效。
  2. 任務進度可顯示於個人、附近或組隊頻道。
  3. 點選任務怪時，可顯示該任務怪的任務進度。
  4. 可自行調整感應距離與角度。
  5. 提醒視窗可選擇全黑／半透明／透明背景，並可自由調整大小及位置。
檔案使用介紹
  1. 安裝後，小地圖會出現 Q 按鈕。
  2. 點擊 Q 開啟 FQT 設定視窗。
  3. 可自行勾選相關設定。
  4. 預設所有功能皆為開啟狀態。
  5. 視窗可使用右上角 X、ESC 或「完成」關閉。

FMV｜商人視窗自由移動
目前版本：v0.01
檔案功能介紹
  1. 原生商人視窗可以自由拖曳。
  2. 自動記住商人視窗最後位置。
檔案使用介紹
  1. 與商人 NPC 對話開啟商店。
  2. 拖曳商人視窗上方標題列即可移動位置。
  3. 下次開啟商人視窗時，會回到上次的位置。

FMAIL｜郵箱加強
目前版本：v0.08
檔案功能介紹
  1. 常用收件人快速選擇。
  2. 收件箱右鍵直接領取附件／金錢。

FWM｜背包自由移動／縮放
目前版本：v0.06
檔案功能介紹
  1. 原本固定位置的合併背包可以自由拖曳。
  2. 可以調整背包顯示大小。
檔案使用介紹
  1. 抓住背包上方標題區即可自由移動。
  2. 滑鼠位於背包區域時，按住 Ctrl＋滑鼠滾輪調整大小。
  3. Ctrl＋向上滾＝放大；Ctrl＋向下滾＝縮小。
  4. 背包位置與大小會自動保存。

FUI｜小地圖按鈕收納器
目前版本：v0.02
檔案功能介紹
  1. 自動收納相容的小地圖插件按鈕。
  2. 平時只顯示 U 按鈕，減少小地圖周圍按鈕過多的情況。
  3. 點擊 U 可展開或收起已收納的按鈕。
  4. 展開後，按鈕會由 U 向左排列。
  5. 支援相容的 BY老哥 UI 及第三方插件按鈕。
檔案使用介紹
  1. 安裝後，小地圖會出現 U 按鈕。
  2. 點擊 U 展開已收納的小地圖按鈕。
  3. 再次點擊 U 即可將按鈕收起。
  4. U 按鈕可沿小地圖外圈拖曳調整位置。
  5. 新增相容插件後，FUI 會自動偵測，不需另外設定。

FWT｜位面交換器（半成品）
目前版本：v0.58
檔案功能介紹
  1. 顯示自己目前位面。
  2. 顯示他人目前所在位面。
  3. 可向他人申請組隊，將自己改變到他人的位面。
  4. 挖礦、採集、獵人抓稀有寵物，很好用。

  1. 安裝後即可使用。
  2. 有安裝本 UI 且為同陣營的人才能看到彼此。
  3. 小地圖 F 按鈕可開啟介面。
  4. 因為需要同陣營多人協助測試本 UI，目前沒有人能幫忙， 只能先提供偵測自己位面為主。等到有人願意幫忙測試， 成功的時候會再做更新。

UI 安裝方式

1. 下載需要的 UI ZIP 壓縮檔。
2. 將 ZIP 解壓縮。
3. 將 UI 資料夾放入《魔獸世界：永恆》的 AddOns 資料夾。
4. 安裝完畢後，可以在遊戲對話框中輸入/reload 或是重新啟動遊戲。
5. 如果沒有啟動，可在遊戲中，按下ESC--插件，確認是否啟用打勾。
